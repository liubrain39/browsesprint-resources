# BrowseSprint 浏览任务记录资源

本仓库提供免费指南、空白 CSV 和对照记录方法，供用户排查一次具体的网页浏览任务为何耗时。项目官网：[BrowseSprint](https://codexbrowse.site/)。

目前没有已发布的浏览器扩展、自动计时服务或已验证的提速结果。本项目与 OpenAI 没有隶属或合作关系。

## 使用方法

1. 先写明公开网页地址、预期结果，以及错误、遗漏和失败的判定标准。
2. 保留三次原方法记录，失败和超时也保留。
3. 根据观察到的问题，只改变一个因素。
4. 在可比条件下，保留三次改动后的记录。
5. 同时比较正确性和耗时，无法观察的值留空。

六次运行只是一次小范围排查，不能证明某种方法适合全部任务。

## 资源

- [空白计时 CSV](browser-task-benchmark.csv)：三行原方法、三行改动后方法，没有填入示例用时或测试结论。
- [本地CSV检查脚本（英文说明）](docs/worksheet-checker.md)：可运行的Python标准库示例，分别保留成功标记、失败与未核验记录；不操作浏览器或自动生成提速结论。
- [已执行的Crawlee HTTP示例（英文）](examples/crawlee-content-gate/README.md)：同一公开网页的正确标题条件和故意错误条件，区分请求完成与内容检查；未执行浏览器、LLM或提速对照。
- [结果核验实例（英文）](docs/browser-result-verification.md)：三种实际核验情况和可复现的公开 HTML 检查，不含用时或提速结论。
- [记录方法与字段说明（英文）](docs/browser-task-protocol.md)：成功标准、起始条件、字段含义和结论边界。
- [对照报告模板（英文）](comparison-report-template.md)：记录设置、观察结果和仍不确定的内容。
- [官网排查指南（英文）](https://codexbrowse.site/codex-browser-slow)：无需报名即可阅读。

下载 CSV 后，用表格或文本编辑器填写。把 `cold_or_reused` 改为实际使用的会话状态。时间字段统一用秒；没有观察到的数据留空，不填成 0。

总耗时和局部阶段时间可能重叠，局部时间不能直接相加。两次可见动作之间的间隔，不等于模型内部思考时间。改变任务、页面、工具配置和预期结果中的多个因素后，也不能把差异归因于一个改动。

如需在仓库反馈，只分享公开页面和可公开的记录，不上传账号凭据、Cookie、私人页面或保密日志。官网的[研究报名](https://codexbrowse.site/#research)只用于研究交流或未来测试，发布时间尚未确定。
